# Deep learning (2015)

## Citation

LeCun, Yann, Yoshua Bengio, and Geoffrey Hinton. "Deep learning". Nature 521, no. 7553 (28 May 2015): 436-444. https://doi.org/10.1038/nature14539.

## One-line summary

The three Turing laureates set out the case for deep learning, explaining how layered representation learning trained by backpropagation transformed speech, vision, and language, and forecasting further gains from cheap computation and data.

## Key claims

- Deep learning lets models composed of many layers learn representations of data at multiple levels of abstraction.
- These methods dramatically improved the state of the art in speech recognition, visual object recognition, and object detection.
- Deep learning discovers structure in large data sets using the backpropagation algorithm to adjust internal parameters layer by layer.
- Deep convolutional nets drove breakthroughs in images, video, speech, and audio; recurrent nets advanced sequential data.
- Representation learning lets a machine discover the representations needed for detection or classification from raw data.
- The features in deep systems are learned from data by a general-purpose procedure, not designed by human engineers.

## Excerpts

> "Deep learning allows computational models that are composed of multiple processing layers to learn representations of data with multiple levels of abstraction."
~ "Abstract", Nature 521(7553), 2015

> "Deep learning discovers intricate structure in large data sets by using the backpropagation algorithm to indicate how a machine should change its internal parameters that are used to compute the representation in each layer from the representation in the previous layer."
~ "Abstract", Nature 521(7553), 2015

> "Representation learning is a set of methods that allows a machine to be fed with raw data and to automatically discover the representations needed for detection or classification."
~ Nature 521(7553), 2015

> "The key aspect of deep learning is that these layers of features are not designed by human engineers: they are learned from data using a general-purpose learning procedure."
~ Nature 521(7553), 2015

> "We think that deep learning will have many more successes in the near future because it requires very little engineering by hand, so it can easily take advantage of increases in the amount of available computation and data."
~ Nature 521(7553), 2015

## Reveals about tendency of thought

- Learned over engineered: Hinton and his co-authors prize features learned from data, the thesis he defended through decades of scepticism.
- Backpropagation at the core: the review centres the algorithm he helped popularise as the engine of the field.
- Forecasting confidence: the closing prediction that scale and data will keep paying off anticipates the later large-model era.
- Shared authorship: writing with LeCun and Bengio marks the public consolidation of the deep learning programme by its three founders.

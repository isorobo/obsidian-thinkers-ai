# Learning a Natural Language Interface with Neural Programmer (2017)

## Citation

Arvind Neelakantan et al. (2017). *Learning a Natural Language Interface with Neural Programmer*. ICLR 2017. https://arxiv.org/abs/1611.08945

## One-line summary

Neural Programmer learns to compose discrete arithmetic and logical operations on tables from weak supervision (final-answer-only), achieving competitive accuracy on WikiTableQuestions without semantic parsing annotations.

## Key claims

- A single end-to-end model induces multi-step programs over table operations using only natural language questions and gold answers.
- Weak supervision avoids the cost of annotated logical forms required by traditional semantic parsers.
- Achieves 34.2% accuracy on WikiTableQuestions, competitive with human-engineered semantic parsers of the era.
- Demonstrates a path from end-to-end neural networks toward symbolic reasoning capabilities.
